# Andrian Cedric portfolio

This repository is the source for a static Next.js App Router portfolio on GitHub Pages.

- Keep navy–cyan branding, Plus Jakarta Sans, and a floating glass navbar.
- Main audience: Product/UI/UX recruiting; freelance work is secondary.
- Use npm and preserve package-lock.json. Node.js 22 is used in CI.
- Run `npm run typecheck` and `npm run build` before completing code changes.
- All local href/src URLs must use `sitePath()` from `lib/site-path.ts` so repository subpaths work. Hash-only links and external links do not need it.
- Keep fonts local; CSS font URLs are bundled from public/fonts.
- Preserve static export. Do not add server actions, request-time APIs, authentication, or runtime database dependencies without discussing hosting changes.
- Never invent project impact metrics, employment titles, timelines, or ownership. Use verified CV and user corrections.
- Do not copy Sites credentials, source-repository tokens, or .openai hosting identity into this repository.
- Source of this migration: initial portfolio created in Sites, September 2026. Future GitHub changes do not automatically update the separate Sites publication.
